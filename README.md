# FalconEye — Space Station Safety Object Detection

SkyHack 2.0 | Category B: Duality AI Challenge

FalconEye is a YOLOv8m-based object detection system trained to identify 
7 critical safety objects inside a simulated space station environment, 
using synthetic data generated by Duality AI's Falcon platform.

---

## Target Classes

| # | Object |
|---|--------|
| 0 | Oxygen Tank |
| 1 | Nitrogen Tank |
| 2 | First Aid Box |
| 3 | Fire Alarm |
| 4 | Safety Switch Panel |
| 5 | Emergency Phone |
| 6 | Fire Extinguisher |

---

## Methodology

- Base Model: YOLOv8m pretrained on COCO
- Training Method: Transfer Learning and Fine-Tuning
- Augmentation: Mosaic, Flip, HSV shift, Rotation, Scale
- Optimizer: AdamW with cosine learning rate decay and early stopping
- Evaluation: mAP@0.5 and Confusion Matrix on held-out test set
- Dataset: Synthetic images generated via Duality AI Falcon platform

## Setup and Installation

### 1. Clone the repository
git clone https://github.com/thrishavc/Falconeye.git
cd Falconeye

### 2. Create virtual environment
py -3.11 -m venv falconeye_env
falconeye_env\Scripts\activate

### 3. Install dependencies
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
pip install ultralytics opencv-python matplotlib seaborn streamlit pillow pyyaml tqdm

### 4. Update dataset paths in yolo_params.yaml
train: <your_path>/data/train_3/train3
val:   <your_path>/data/train_3/val3
test:  <your_path>/data/test3

---

## Training

# Baseline training (50 epochs)
python train.py

# Optimization round (100 epochs with augmentation)
python optimize.py

## Evaluation

# Run full evaluation on test set
python evaluate.py

# Run predictions and save output images
python predict.py

## How Falcon Improves This Model

Duality AI Falcon enables a continuous improvement loop:
1. Identify weak classes via confusion matrix
2. Generate targeted synthetic data for those classes in Falcon
3. Retrain model with expanded dataset
4. Deploy improved model

This closed loop allows accuracy to improve continuously over time,
which is not achievable at this scale with real-world data collection.
